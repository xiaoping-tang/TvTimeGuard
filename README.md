# 电视时间管家（TvTimeGuard）

用来管理小孩看电视时间的 Android App。家长在手机上设置规则，电视到点自动提示并关机。**人不在家也能远程控制**。

- 当前版本：**v1.6**
- 电视：小米 Xiaomi TV A Pro 43" QLED 2026（L43MB-APSEA，Google TV）
- 手机：小米手机（Android）
- 安装包：仓库根目录的 [`TvTimeGuard.apk`](TvTimeGuard.apk)

## 工作原理

同一个 APK 同时装在电视和家长手机上，第一次打开时选择这台设备的用途。

```
 家长手机 (遥控)  ──设置/指令──▶  ntfy.sh 中转  ──▶  电视 (计时 + 管控)
                 ◀──状态上报──               ◀──
```

- **电视端**：在电视本地计时、判断规则，到点后用本机 ADB（127.0.0.1:5555）让电视待机。手机不在身边、电视断网时，仍按最后一次收到的设置管控。
- **手机端**：只当遥控器。通过免费的公共消息中转站 [ntfy.sh](https://ntfy.sh)（无需注册）给电视发设置、看状态，所以在外面也能用。
- **配对码**：电视端随机生成，两边用它找到对方。

## 功能

**家长手机：**
- 每天最多看多少分钟、允许看电视的时段（如 07:00–21:00，可跨午夜）
- 快捷操作：今天加 15 / 30 / 60 分钟、**做题加时**、立即关电视、暂停管控 1 小时、恢复管控、今日时间清零
- 做题加时每天最多能加多少分钟（默认 60）
- 查看电视状态：是否开着、今天已看多久、多久前上报

**电视：**
- **今天的时间用完了 → 直接进入做题界面**（v1.3），不再弹关机倒计时；开机时时间已用完，也直接进做题
  - 题目**全部来自新加坡各校真题**（v1.6）：P5 英文 / 数学 / 高级华文（2025 年终考），Sec 2 英文（2016 SA1）/ 数学（2024 年终考）/ 科学（2022 年中、年终考）。每题都显示出处（哪所学校哪次考试）
    - 出题比例：**P5 : Sec 2 = 3 : 1**；**P5 英文 : 数学 : 华文 = 2 : 1 : 1**，**Sec 2 英文 : 数学 : 科学 = 2 : 1 : 1**（即 P5 英文 6/16、P5 数学 3/16、P5 华文 3/16、Sec 2 英文 2/16、Sec 2 数学 1/16、Sec 2 科学 1/16）
    - 题量：P5 英文 602、P5 数学 487、P5 华文 210、Sec 2 英文 157、Sec 2 数学 439、Sec 2 科学 382，洗牌出题，一科全部做完一轮才重复
    - 作答方式按题目自动切换：**填数字**（数字键盘，只填数字不带单位；分数用 `/`，负数用 `-`，等值的小数也算对）、**填一个英文单词**（字母键盘，如改错、短文填空）、**四选一**（原卷选择题；华文因为遥控器没法输入汉字，全部是四选一）。选择题容易蒙对，所以**答错后要先看 15 秒解释**才能做下一题
    - 原卷里需要看图的题（图形、统计图、看图写作等）没法在电视上显示，大多跳过，简单的图改写成文字；写作、听力、开放式问答也跳过。答案以各校答案为准并逐题复核过，少数答案明显有误的已更正或删掉
    - 题库都是 `app/src/main/assets/` 下的文本文件，一份考卷一个文件，一行一题，格式见下面「项目结构」。考卷 PDF 放在本机 `papers/` 目录，不上传 GitHub
    - 以前自编的题库（英文填空、华文选择）和随机数学题生成器已搁置：题库文件移到 `old_banks/`，不再打包进 APK，代码还在，以后需要可以再接回来
  - 做题界面盖上来时，YouTube 等播放器退到后台会自动暂停；**答对 1 题 = 看 10 分钟**，做题界面关闭后回到原来的视频并自动接着播；这 10 分钟用完后，再回到做题界面
  - 如果电视时间管家被 Google TV 暂停（儿童资料、家长控制、屏幕使用时间限制），做题界面打不开，这时改为 60 秒后直接关电视；请在 Google TV 里把电视时间管家设为允许使用
  - 答错：显示正确答案和解释（数学题是分步解答），按「Next question」做下一题
  - 做题时不计观看时间；按主页键溜走会被拉回做题界面
  - 按返回键或「Give up」= 放弃做题，改走原来的 60 秒倒计时关机（家长可以在倒计时界面输密码）
  - 每天做题加时达到上限（家长在手机上设置，默认 60 分钟）后，时间用完就照旧倒计时关机
  - P5 数学题型（22 类，参数随机）：分数及剩余部分（正推/倒推）、分数的分数、带分数、比（变化前后/按比分配/差）、百分数（折扣/分组）、平均数、体积与容量（注水/水位上升/装正方体）、三角形面积、小数与钱、盈亏问题、租车、年龄问题、鸡兔同笼、速率
- 不在允许时段、家长远程关机时，照旧全屏显示「看电视的时间到了」，**倒计时 60 秒**后关机
- 倒计时界面上**输入 4 位家长密码**，可暂停管控 1 小时
- 家长也可以随时在手机上点「📝 做题加时」，电视 30 秒内出题（电视待机时按下，10 分钟内开机也会出题）
- 10 分钟内被关过又重新开机，只给 **20 秒**短倒计时，防止反复开关机蹭时间
- 按主页键会在 1 秒内被拉回倒计时界面，按返回键无效
- 停止守护、查看配对码、更换配对码、修改密码、更改设备用途，都需要家长密码

**安全设计（v1.1 新增）：**
- **手机配对前只计时、不关机**，保证家长能完整走完安装步骤
- 无论何时开机，都会先显示倒计时界面，家长总有机会输密码解锁，不会被锁死在"一开机就关"的循环里

## 安装步骤

### 电视（只需做一次）

1. **打开开发者选项**：设置 → 系统 → 关于，找到「**Android TV OS 版本号**」（英文界面叫 *Android TV OS build*），用遥控器确认键连按 7 次，直到提示已进入开发者模式。
2. **打开 USB 调试**：设置 → 系统 → 开发者选项 →「USB 调试」。
3. **安装 APK**：把 `TvTimeGuard.apk` 拷进 U 盘插到电视上，用文件管理器打开安装；或者在电视上装 *Send Files to TV*，从手机把 APK 发过去。升级时直接覆盖安装，不用先卸载。
4. 打开 App，选「📺 这台是电视」，然后：
   1. **设置 4 位家长密码**（输入两遍）
   2. 点「授权 / 测试 ADB」，电视弹出「允许 USB 调试吗？」时，**勾选「始终允许」**再点「允许」
   3. 点「启动守护」
   4. 点「显示配对码」，输入家长密码后会显示配对码，记下来

### 家长手机

1. 把 `TvTimeGuard.apk` 发到手机上安装，可以用微信文件传输助手或 USB 线。小米手机提示"未知来源"或"有风险"时，选允许或继续安装。
2. 打开 App，选「📱 这台是家长手机」。
3. 在「配对」处输入电视上的配对码，点「保存配对码」。保存时会自动把设置发给电视，**电视收到后才开始真正管控**。
4. 按需要修改规则，点「保存并发送到电视」，约 30 秒内生效。

### 装好后建议先试一次

在手机上把允许时段的结束时间设成几分钟后，然后观察：电视应该弹出倒计时，输家长密码能解锁。确认这一步正常后，再改回正常规则。

## 出问题时怎么办

| 情况 | 处理 |
|---|---|
| 电视一开机就弹倒计时，想正常看 | 输入家长密码，暂停 1 小时；或者在手机上点「+30 分钟」、「暂停管控」 |
| 「授权 / 测试 ADB」失败 | 确认 USB 调试已打开；授权弹窗要勾选「始终允许」。仍然失败的话，可能是这台电视不开放本机 5555 端口，需要改用「无线调试」方案 |
| 状态显示"想关电视但 ADB 失败" | 在电视 App 里重新点「授权 / 测试 ADB」 |
| 手机显示"电视很久没上报" | 电视可能在待机或断网，也可能 App 被小孩强制停止或卸载了。电视明明开着却不更新，多半是家里网络当天的 ntfy.sh 免费额度（每天 250 条）用完了，第二天恢复 |
| 手机发指令提示"免费消息额度用完了" | 手机关掉 Wi-Fi、改用流量再发（流量是另一个网络，有自己的额度） |
| 忘记家长密码 | 设置 → 应用 → 电视时间管家 →「清除数据」，然后重新设置并重新配对 |
| 完全进不去电视（v1.0 的老问题） | 拔电源冷启动，主界面一出现，马上进 设置 → 应用 → 电视时间管家 →「强制停止」，然后装 v1.1 |

## 已知限制

- **真机验证还没完成**：本机 ADB、倒计时、远程关机都在 Android TV 模拟器上测试通过，但还没在这台小米电视上完整跑一遍。v1.0 在真电视上已确认 ADB 授权和关机可用。
- 小孩如果会进设置去「强制停止」或卸载 App，管控就失效了。这种情况可以从手机端"很久没上报"发现。
- 手机发出的指令，电视 30 秒内执行，执行后马上回报状态。平时电视只在状态有变化时上报（开着时至少每 10 分钟一次、待机时每小时一次），所以"已看多少分钟"可能比实际落后几分钟。
- ntfy.sh 免费服务每个网络每天最多 250 条消息，电视上报和手机在家里 Wi-Fi 下发的指令共用这个额度。v1.4 已大幅减少上报次数（v1.3 及以前上报太频繁，会把额度用光）。
- 电视的时区要设对（新加坡），否则允许时段会算错。
- 消息经过 ntfy.sh 公共服务器，内容只有时长设置和观看分钟数。**配对码就是遥控钥匙**，不要外传；怀疑泄露时在电视端「更换配对码」。

## 开发

### 项目结构

```
app/src/main/java/com/family/tvtimer/
├── MainActivity.kt   主界面：选择用途 / 电视端 / 手机端
├── GuardService.kt   电视端前台守护：拉取指令、计时、倒计时关机、上报状态
├── LockActivity.kt   「时间到了」全屏倒计时 + 家长密码键盘
├── TvController.kt   本机 ADB（dadb 库）：让电视待机、启动倒计时界面
├── Relay.kt          ntfy.sh 收发消息
├── QuizActivity.kt   「做题加时」全屏做题界面（数字键盘 / 字母键盘 / 四选一）
├── Quiz.kt           出题比例、真题题库读取（PaperBank）、精确分数 Frac；搁置的自编题库和 P5 数学生成器
├── QuizSec2.kt       Sec 2 数学题生成器（已搁置）
├── Prefs.kt          设置和当天观看记录
├── Ui.kt             按钮样式（遥控器选中高亮）和数字键盘
└── BootReceiver.kt   开机或升级后自动恢复守护
app/src/main/assets/p5_*/、sec2_*/  真题题库，一份考卷一个 txt，一行一题，7 段：
        作答方式|题型|题目|答案|干扰项|讲解|出处
        作答方式 N=填数字、W=填一个英文单词（多个可接受答案用 / 分隔）、C=四选一（3 个干扰项用 ~ 分隔）
        N 和 W 的干扰项留空；题目和讲解里的 \n 表示换行
old_banks/                     搁置的自编题库（不打包进 APK）
papers/                        考卷 PDF（只在本机，.gitignore 忽略）
app/src/test/                  单元测试：每道真题都能解析、标准答案判对、干扰项判错、长度放得下、不重复；出题比例
```

ntfy 主题（topic）：`tvtimer-<配对码>-cmd`（手机 → 电视），`tvtimer-<配对码>-st`（电视 → 手机）。

### 编译

需要 JDK 17 或更高版本，以及 Android SDK（platform 35、build-tools 35）。最省事的是用 Android Studio 打开项目。命令行编译：

```powershell
# local.properties 里写 sdk.dir=C:/path/to/Android/sdk
.\gradlew assembleRelease
copy app\build\outputs\apk\release\app-release.apk TvTimeGuard.apk
```

release 包用仓库里的 [`keystore/debug.keystore`](keystore/debug.keystore) 签名（`app/build.gradle.kts` 里已经指定），**任何电脑编译出来的签名都一样，可以直接覆盖安装**。这个文件就是装在电视和手机上那个 App 的"钥匙"，丢了或换了就只能卸载重装，**不要删除，仓库也不要改成公开**。
