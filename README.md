怎么实现"不在家也能控制"
同一个 APK 装两处，第一次打开时选这台设备是电视还是家长手机：

电视：App 在电视上计时，到点就让电视待机。手机没电、不在家，管控照样有效；电视断网也会继续按上一次的设置管。
手机：只当遥控器。设置和指令通过免费的公共中转站 ntfy.sh（不用注册）发到电视，电视也从这里上报状态。
手机端能做的事：

设每天最多看多少分钟、允许看电视的时段（比如 07:00–21:00）
临时加 15 / 30 / 60 分钟、立即关电视、暂停管控 1 小时、今日时间清零
查看电视现在开没开、今天已看多少分钟
时间用完或不在允许时段时，电视会在 30 秒内自动待机；小孩再打开，会马上又被关掉。

安装步骤
电视（只需操作一次）：

打开开发者选项：设置 → 系统 → 关于，在「Android TV OS 版本」上连按 7 次。
开发者选项里打开「USB 调试」。
把 APK 装到电视上。最简单的是告诉我电视的 IP 地址（设置 → 网络里能看到），我从这台电脑通过局域网直接装；也可以用 U 盘 + 文件管理器装。
打开 App，选「这台是电视」：
点「授权 / 测试 ADB」，电视弹窗时勾选「始终允许」再点允许
点「启动守护」
点「显示配对码」，记下这个码
小米手机：

把 APK 发到手机安装（微信、USB 都可以），选「这台是家长手机」。
输入配对码，设好规则，点「保存并发送到电视」。
需要你知道的几点
最大的不确定点：App 是在电视本机打开调试通道，再用它让电视待机。大多数 Google TV 打开 USB 调试后都能这样用，但我没法在你的电视上实测。如果「授权 / 测试 ADB」失败，把报错发给我，我再换方法。
配对码等于遥控钥匙：知道配对码的人都能控制电视，所以不要让小孩看到。配对码平时是隐藏的。消息经过 ntfy.sh 公共服务器，内容只有时长设置和观看分钟数，没有别的个人信息。
小孩能绕过的情况：小孩如果会进设置去「强制停止」或卸载这个 App，管控就失效了。这时手机上会显示"电视很久没上报"，你可以由此发现。
手机上显示的状态最多延迟约 5 分钟；你发出的指令，电视在 30 秒内执行。

家里电脑有两种下载方法：

方法 1：网页直接下载（最简单，不用装任何软件）
在浏览器打开 https://github.com 并登录你的账号 xiaoping-tang
打开 https://github.com/xiaoping-tang/TvTimeGuard
按需要选一种：
只要安装包：在文件列表里点 TvTimeGuard.apk，再点右上角的下载按钮（↓ 图标）
要整个项目：点绿色的 Code 按钮 → Download ZIP，下载后解压
方法 2：用 Git 下载（以后要同步修改时用这个）
装 Git（装过可跳过）：到 https://git-scm.com/download/win 下载安装，一路点"Next"用默认选项即可。
打开 PowerShell，进入想存放项目的文件夹，比如"文档"：

cd $HOME\Documents
git clone https://github.com/xiaoping-tang/TvTimeGuard.git
登录：因为是私有仓库，第一次会弹出 GitHub 登录窗口，选 Sign in with your browser，在浏览器里登录 xiaoping-tang 并点授权就行。之后会自动记住，不用再登录。
下载完成后，项目在 文档\TvTimeGuard 文件夹里。
